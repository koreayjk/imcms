# 검색 등록 점검표 (크롬 확장 패널용)

크롬 확장 패널(Claude in Chrome 등)에 이 문서를 붙여 넣고 **점검할 매체 주소**만 바꿔서 시킵니다. 이미 로그인해 둔 구글 서치콘솔·네이버 서치어드바이저·다음 검색등록 화면을 눈으로 보며 **읽기만** 하는 점검입니다.

> **규칙 (꼭 지킬 것)**
> - 이 점검에서는 **아무것도 바꾸지 않습니다.** 사이트 삭제, 소유권 해제, 사이트맵 삭제·재제출, "색인 생성 요청", 설정 저장 버튼은 누르지 않습니다. 눌러야 할 것이 보이면 누르지 말고 보고서의 "해야 할 일"에 적습니다.
> - 비밀번호·인증 코드·쿠키·개인 이메일은 보고서에 적지 않습니다. 확인 코드(메타 태그 content 값)는 앞 6글자만 적습니다.
> - 화면에 없는 값은 지어내지 않습니다. 못 본 항목은 "확인 못 함 (이유)"으로 적습니다.

점검할 매체: `https://매체주소/` (예: `https://newstoday.ai.kr/`)
매체 이름: ______

---

## 1. 사이트 자체 점검 (로그인 필요 없음)

주소창에서 아래를 직접 열어 확인합니다.

| 확인 | 열 주소 | 정상 기준 |
|---|---|---|
| 홈이 열림 | `/` | 200, 오류 화면 아님 |
| robots.txt | `/robots.txt` | `Allow: /` 있음, `Disallow: /` 만 단독으로 있지 않음, `Sitemap:` 줄 2개(sitemap.xml, news-sitemap.xml) |
| 사이트맵 | `/sitemap.xml` | 열리고 기사 주소(`/news/…`)가 들어 있음 |
| 뉴스 사이트맵 | `/news-sitemap.xml` | 열림 (최근 기사만 들어 있어도 정상) |
| 검색 허용 표시 | 홈에서 "페이지 소스 보기"(Ctrl+U) 후 `robots` 검색 | `content="index, follow"` (**`noindex`가 보이면 문제**) |
| 구글 확인 코드 | 같은 소스에서 `google-site-verification` 검색 | 메타 태그가 있음 |
| 네이버 확인 코드 | 같은 소스에서 `naver-site-verification` 검색 | 메타 태그가 있음 |
| 대표 주소 | 기사 하나를 열고 소스에서 `canonical` 검색 | 그 기사 자신의 주소 |
| www 연결 | `https://www.매체주소/` | 대표 주소로 이동(308/301) |

보고서에 각 줄을 "정상 / 문제 / 확인 못 함"으로 적습니다.

## 2. 구글 서치콘솔 (search.google.com/search-console)

로그인된 계정으로 열고, 왼쪽 위 속성 선택에서 점검할 매체를 고릅니다. 속성이 안 보이면 "등록 안 됨"으로 적고 이 장은 끝냅니다.

1. **속성 종류**: 도메인 속성(`매체주소`) 또는 URL 접두어(`https://매체주소/`)? → 적습니다.
2. **개요 / 실적**: 최근 3개월 클릭·노출이 0인지, 조금이라도 있는지. 그래프 날짜가 오늘 가까이까지 있는지.
3. **색인 생성 → 페이지**: 맨 위 숫자 "색인이 생성된 페이지"와 "색인이 생성되지 않은 페이지"를 적고, 아래 **이유 목록을 전부** 이름과 개수로 적습니다. 특히 아래 항목이 있으면 크게 표시합니다.
   - 크롤링됨 – 현재 색인이 생성되지 않음
   - 발견됨 – 현재 색인이 생성되지 않음
   - robots.txt에 의해 차단됨
   - 'noindex' 태그에 의해 제외됨
   - 페이지에 리디렉션이 있음 / 소프트 404 / 찾을 수 없음(404)
   - 중복 페이지, 사용자가 선택한 표준 페이지가 없음 / 구글이 선택한 표준 페이지가 다름
4. **색인 생성 → 사이트맵**: 제출된 사이트맵 목록, 각 상태("성공" / "가져올 수 없음" / "오류"), 마지막 읽은 날짜, "발견된 페이지" 수. `sitemap.xml`·`news-sitemap.xml`이 있는지.
5. **URL 검사(위쪽 검색창)에 홈 주소를 붙여 넣고 Enter** (조회만, "색인 생성 요청"은 누르지 않음): 결과 문구를 그대로 적습니다. ("URL이 Google에 등록되어 있습니다" / "URL이 Google에 등록되어 있지 않습니다" 와 이유, 마지막 크롤링 날짜, 크롤링 허용 여부, 색인 생성 허용 여부.)
6. 같은 방식으로 **기사 1건**(홈에서 최신 기사 하나)의 URL 검사 결과도 적습니다.
7. **설정 → 소유권 확인**: 확인된 소유자인지, 확인 방법(HTML 태그 / DNS 등).
8. **보안 및 수동 조치**: 수동 조치·보안 문제가 있으면 문구를 적습니다. 없으면 "없음".

## 3. 네이버 서치어드바이저 (searchadvisor.naver.com)

1. **웹마스터 도구 → 사이트 목록**: 점검할 매체 주소가 등록되어 있는지, **소유 확인 상태**.
2. **요청 → 사이트맵 제출**: 제출된 목록과 상태, 마지막 수집일. (`sitemap.xml`, 가능하면 `rss.xml`)
3. **요청 → RSS 제출**: 제출 여부와 상태.
4. **요청 → 웹 페이지 수집**: 최근 수집 요청 내역이 있는지 (조회만).
5. **검증 → robots.txt**: 네이버가 읽은 robots.txt 내용이 위 1번 표와 같은지.
6. **리포트(색인량·수집 현황)**: 색인된 페이지 수, 수집 오류가 있으면 종류와 개수.
7. **검색 노출**: 네이버에서 `site:매체주소` 와 매체 이름을 각각 검색해 첫 화면에 나오는지.

## 4. 다음(카카오) 검색등록

다음은 구글·네이버와 따로 **검색등록**이 필요합니다. 로그인한 계정으로 다음 검색등록(웹마스터 도구) 화면을 찾아 확인합니다. 화면이 열리지 않거나 메뉴 이름이 다르면 "확인 못 함 (화면 이름이 다름)"으로 적고 보이는 메뉴 이름을 그대로 옮겨 적습니다.

1. 매체 주소가 등록되어 있는지, 등록 상태(승인/검토 중/반려)와 날짜.
2. 사이트맵·RSS 제출 여부.
3. 다음 검색창에서 `매체주소`와 `"매체 이름"`을 검색해 나오는지.

### 해석 도움말 (운영팀용)

- 사이트 자체는 정상인데 구글에서 **"크롤링됨 – 색인 생성 안 됨"** 이 많다 → 구글이 읽고 보류한 것. 사이트 설정 문제가 아니고 콘텐츠 평가·신규 도메인 신뢰 문제. 홈·섹션 색인 요청과 시간이 필요합니다.
- **"발견됨 – 색인 생성 안 됨"** → 구글이 아직 읽지 않음. 사이트맵 제출 상태와 서버 응답 속도 확인.
- **"robots.txt 차단" / "noindex"** 가 나오면 오픈 직후 이전 상태를 구글이 기억하는 경우일 수 있음 → URL 검사 "라이브 URL 테스트" 후 "색인 생성 요청" (이 점검에서는 누르지 말고 해야 할 일로 적기).
- 네이버만 되고 구글·다음이 안 되는 경우: 네이버는 사이트맵·RSS·수집 요청이 따로 되어 있어 빨리 반영되는 편이고, 구글은 색인 판단이 느림. 다음은 별도 검색등록 여부부터 확인.
- 사이트맵 `sitemap.xml`에는 기사 주소가 최대 1000개까지 실립니다(발행 기사가 더 많은 매체는 최신순 1000개).
