# 안내(이용) 영상 제작 프롬프트

아래 `---` 이후 전체를 새 창(다른 프로젝트)에 그대로 붙여 넣는다. `【 】` 안은 프로젝트마다 채운다.

---

## 요청

【프로젝트 이름】의 이용 안내 영상을 만들어 줘. 화면은 **실제 서비스를 직접 조작하며 녹화**하고, 한국어 음성 해설과 아래 규격의 자막·강조 효과를 넣어 1080p mp4로 뽑는다. 유튜브에 바로 올릴 수 있게 제목·설명·챕터 문서와 섬네일까지 같이 만든다.

### 0. 먼저 나에게 확인할 것 (한 번에 모아서 물어보고, 답을 받은 뒤 시작)
1. 만들 영상 목록과 순서 (편마다 한 줄 목적). 한 편은 **1~2분**, 길어도 3분 안.
2. 녹화에 쓸 주소와 **체험(시험) 계정** — 실제 고객 계정·실제 데이터는 쓰지 않는다.
3. 음성 목소리 (처음 한 번만 묻고, 정해지면 다시 묻지 않는다).
4. 마지막에 붙일 로고 영상/이미지와 대표 색.

내가 시키지 않은 일(기사·문구·기능 추가 등)은 하지 않는다. 화면과 다르게 말하지 않는다 — 화면에 없는 기능은 설명하지 않고, 모르면 물어본다.

### 1. 순서 (편마다 반복)
1. **화면 탐색**: 실제로 눌러 보며 흐름·버튼 이름·화면 문구를 그대로 메모한다 (스크린샷으로 확인). 이름은 화면에 적힌 그대로 말한다.
2. **장면 대본**: 장면 1개 = 문단 1개 = 음성 파일 1개. 장면마다 `단계 번호 + 한 줄 자막`을 같이 적는다.
3. **내 승인**: 대본(장면 목록 + 해설 문장)을 보여 주고 승인받은 뒤 녹화한다. 승인 전에는 음성을 만들지 않는다 (유료 크레딧).
4. **녹화** → **음성** → **조립** → **검수** → **유튜브 문서·섬네일**.

### 2. 녹화 규격
- Playwright(Chromium)로 `recordVideo`, 뷰포트 **1280×720**. 한 편을 한 번에 이어서 녹화하고, 장면 시작 시각을 로그(`SCENE 이름 초`)로 남겨 나중에 장면별로 자른다.
- 화면 위에 **오버레이**를 init script로 넣는다 (녹화에 같이 찍힘):
  - 마우스 **커서**(검은 화살표 + 흰 테두리), 클릭할 때 **물결 링**(대표색, 56px → 1.9배로 퍼지며 사라짐)
  - 누를 대상에 **강조 테두리**(대표색 4px, 바깥 번짐)
  - 아래 가운데 **자막 막대**: 어두운 반투명 배경, 27px 굵은 글씨, 왼쪽에 **단계 번호 배지**(대표색 알약). 한 줄 20자 안팎, 단어 중간에서 줄바꿈하지 않는다 (`word-break: keep-all`).
- 동작 헬퍼: `go`(대상으로 28스텝 이동 후 0.9초 멈춤) · `click`(이동→클릭) · `type`(느리게 한 글자씩, 85ms). 사람이 따라 할 수 있는 속도로 움직인다.
- 시작 전에 사전 로딩을 하고 **앞부분은 잘라 낸다**. 화면이 바뀐 직후엔 로딩이 끝날 때까지 기다렸다가 말을 시작한다.
- 이 환경 프록시는 동시 연결이 많으면 끊기므로, 브라우저 요청을 **한두 개씩 차례로** 받게 하고(실패 시 재시도), 업로드·저장(POST 등)은 그대로 보낸다.
- 실제 저장·발송·결제·삭제처럼 **되돌릴 수 없는 동작은 화면만 보여 주고 실행하지 않는다.** 체험 계정에서 만든 데이터는 녹화 뒤 반드시 **정리**한다.
- 개인정보(이메일 주소, 전화, 카드, 토큰, 확인 코드)는 **가림 처리**하거나 예시 값으로 바꾼다.

### 3. 음성 해설
- 해설은 **짧고 또렷한 존댓말**, 화면에서 보이는 순서대로. 한 문단에 한 동작. "먼저 / 그다음 / 마지막으로" 같은 길잡이를 쓴다.
- 영어·약어·숫자는 소리 나는 대로 한글로 적는다 (예: `AI` → 에이아이, `OR` → 오아르, `Ctrl+V` → 컨트롤 V). 문장 안에서 따옴표·괄호 읽기는 풀어 쓴다.
- 장면 하나씩 따로 음성 파일로 만든다(`n1.wav, n2.wav …`). 대본 줄 수와 파일 수가 어긋나면 안 된다. 한 파일에 여러 줄을 받았다면 **무음 구간 검출**(`silencedetect=noise=-33dB:d=0.13`)로 줄 수만큼 나눈다.
- 음성은 유료 크레딧이 든다 — 글자 수와 비용을 먼저 알리고, 시험 한 줄로 목소리를 확인한 뒤 전체를 만든다.
- 마지막 장면은 서비스 이름 한 줄(예: "아이엠 뉴스룸")을 로고에 맞춰 말한다.

### 4. 조립 (ffmpeg, 최종 1920×1080 / 30fps)
- 장면마다: 녹화에서 해당 구간을 자르고(`-ss/-t`, 필요하면 여러 조각을 이어 붙임) 1920×1080으로 맞춘다 (`scale + pad`, 여백은 흰색).
- **길이 결정**: 장면 길이 `L = max(원본길이 ÷ 최대배속, 음성길이 + 0.7초)`. 음성이 길면 화면을 **마지막 프레임으로 멈춰** 맞추고(`tpad`), 화면이 길면 최대 배속 안에서 빠르게 돌린다. 배속은 **0.8~최대배속** 사이, 기본 최대 1.6배 안팎 — 클릭·입력처럼 보여 줘야 하는 구간은 1배로 둔다.
- 음성은 장면 시작에서 0.15초 뒤에 깔고(`adelay`), 장면 길이에 맞춰 무음으로 채운다. 음성 없는 장면은 2.2초 이상.
- 영상과 음성을 장면별로 따로 이어 붙인 뒤(concat) 합치고, 마지막에 **로고 마무리 장면**(대표색 배경, 약 6초, 음성은 2.3초 뒤에서 시작)을 붙인다.
- 최종 인코딩: 영상 `libx264 -crf 14 -preset medium -pix_fmt yuv420p`, 음성 `aac 192k 48kHz`, **`loudnorm=I=-16:TP=-1.5:LRA=9`** + 끝 0.6초 페이드아웃, 영상 앞 0.4초 페이드인/끝 페이드아웃, `+faststart`.
- ffmpeg는 `imageio_ffmpeg.get_ffmpeg_exe()` 경로를 쓴다. 장면 길이 검증(`assert`)을 넣어 어긋나면 멈춘다.

### 5. 검수 (내게 주기 전에 반드시)
- 최종 mp4에서 **장면마다 프레임을 뽑아** 직접 본다: 자막이 잘리지 않았는지, 개인정보가 보이지 않는지, 클릭 대상과 강조 테두리가 맞는지, 로딩 중 빈 화면이 없는지.
- 음성과 화면이 **같은 순간**을 말하는지(말하는 버튼이 그때 눌리는지) 확인한다.
- 총 길이, 파일 크기, 해상도, 장면별 배속을 요약해서 보고한다. 못 확인한 것(소리 품질 등 직접 들어야 하는 것)은 솔직히 "확인 못 함"이라고 적는다.
- 화면이 바뀌어 대본과 달라진 부분이 있으면 숨기지 말고 알려 준다.

### 6. 함께 만들 것
- **유튜브 문서** `영상별-유튜브.md` (편마다):
  ```
  ## N편 — 파일이름.mp4
  제목
  【서비스 이름】 사용법 N | 핵심 내용: 구체적인 검색어 두세 개를 넣은 한 줄
  설명
  무엇을 하는 영상인지 2~3문장 (총 길이)
  0:00 장면 이름
  0:09 다음 장면 …          ← 챕터는 실제 조립 결과의 시각으로, 0:00부터
  · 주의할 점(체험 계정이라 실제로 보내지 않는다 등)
  · 화면의 데이터는 설명을 위한 예시입니다.
  서비스 주소
  #태그 #태그 …
  ```
- **섬네일** 1280×720 PNG: 편 번호 + 큰 제목 두세 줄(멀리서도 읽히게), 대표색, 서비스 로고. HTML을 Playwright로 캡처한다. 한글 글꼴은 Pretendard(woff2를 파일로 넣어 사용).
- 영상 목록 표(번호·제목·길이·파일명)와 "다시 찍어야 하는 영상" 표 — 서비스 화면이 바뀌면 어느 편을 갱신할지 알 수 있게.

### 7. 지켜야 할 것
- 파일 이름 규칙: `서비스명-사용법-NN-제목.mp4`, 섬네일 `…-섬네일.png`. 이전 판은 `-이전판`을 붙여 따로 둔다 (덮어쓰지 않는다).
- 한 번에 한 편씩 끝내고 내게 확인받는다. 여러 편을 한꺼번에 만들 때도 편마다 검수 결과를 보고한다.
- 임시 파일은 작업 폴더 밖 임시 디렉터리에 두고, 결과물만 내게 보낸다(파일 보내기 도구 사용).
- 크레딧·시간이 많이 드는 단계(음성 전체 생성, 최종 인코딩) 전에는 예상 비용·시간을 먼저 말한다.
- 화면에서 보지 못한 기능을 추측해서 말하지 않는다.
