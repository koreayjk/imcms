# 작업 인수인계 (2026-11-01 기준)

이전 세션의 대화는 새 세션으로 옮겨지지 않는다. 이 문서가 그 대신이다. 새 세션은 `CLAUDE.md`와 이 문서를 먼저 읽고, **사용자가 시키지 않은 일은 시작하지 않는다.**

## 1. 사용자와 지킨 약속
- 답은 **한국어**로 한다. 짧고 쉬운 말로, 모르는 것은 "확인 못 했다"고 솔직히 쓴다.
- 개발과 푸시는 브랜치 `claude/new-session-tdsge1`에만 한다 (Vercel 자동 배포). 사용자가 요청하지 않으면 PR은 만들지 않는다.
- 푸시 전: `git pull -q --rebase origin claude/new-session-tdsge1`, 그리고 `npx tsc --noEmit -p .`가 통과해야 한다. 실패하면 푸시하지 않는다.
- 커밋 메시지 끝에 두 줄을 붙인다: `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>` / `Claude-Session: <세션 주소>`.
- Next.js 16이다. 코드를 쓰기 전에 `node_modules/next/dist/docs/`의 관련 안내를 읽는다 (`AGENTS.md`).
- DB(Supabase)는 이제 `mcp__Supabase__execute_sql`로 직접 쓸 수 있다. 규칙은 `CLAUDE.md`의 "운영 DB 사용 규칙"을 따른다. 사용자가 SQL 실행을 맡길 때만 쓰고, 삭제·대량 변경은 먼저 말한다. 사용자가 직접 실행해야 하는 SQL은 파일(`supabase/*.sql`)로 주고 파일 이름과 순서를 말한다.
- `sleep`으로 기다리지 않는다. 프로세스를 끌 때는 `kill $(lsof -ti:포트)`를 쓴다 (`pkill -f` 금지).

## 2. 운영 DB 정보 (읽기 전용 확인 결과)
- Supabase 프로젝트 `imcms` (id `xmkrpjsetdneulyyasrf`, 도쿄)가 IM뉴스룸 DB다 (사용자 확인). 같은 계정의 다른 프로젝트(aim, lifememory, IM VOCA, tcs, svm)는 건드리지 않는다.
- `articles.status`: `draft` / `in_review`(승인대기) / `published` / `rejected`.
- 주요 열: `outlet_id, category_id, author_id(필수), byline, title, body(html), excerpt, tags(text[]), thumbnail_url, press_release_id, ai_notes, published_at`.
- 보도자료함 `press_releases`: 제목·링크·요약(290자 안팎)만 있고 `body_html`은 대부분 비어 있다. **본문은 `link`의 원문 페이지를 읽어서 쓴다.** `publisher_id`가 비어 있거나 매체의 그룹과 같은 것만 그 매체에 보인다.
- 매체 설정 `outlets.site` (jsonb): `lang`(`ko`/`en`), `aiNotice` = `{"on": true, "text": "..."}` 이 켜져 있으면 본문 끝에 `<p><em>※ 문구</em></p>`를 붙인다. 영문 매체(`lang = 'en'`)는 본문 첫머리 기자 표기를 넣지 않는다.
- 본문 첫머리 표기: `<p>[매체이름=기자이름 기자]&nbsp;첫 문장…</p>` (한국어 매체).

## 4. 아직 안 끝났거나 사용자가 정해야 하는 일
- **8개 매체 자동 작성 (논의 단계, 아무것도 예약하지 않았다)**: 대상은 더케어타임즈·Israel Today를 뺀 나머지 8개 (사용자가 올린 화면 기준: Shipping Times, 에듀와이드, 다음세대타임즈, The Statecraft Times, 치앙마이미션타임즈, 치앙마이 타임즈, Breaking BCS, 말레이시아 타임즈. 화면 위쪽이 잘렸을 수 있으니 `outlets` 표로 다시 확인할 것). 매체마다 하루 10건, 매체 사이는 1시간 간격, 승인대기로 올린다.
  - 사용자 방향: API가 아니라 **이 세션처럼 제가 직접 쓰는 방식**.
  - 합의된 시작: 치앙마이 타임즈 1곳만 먼저 예약으로 시험 → 잘 되면 7곳 추가.
  - 예약은 `mcp__Claude_Code_Remote__create_trigger`의 `create_new_session_on_fire`(시각마다 새 세션)를 권했다. 새 세션이 Supabase에 쓸 수 있는지는 **아직 확인하지 못했다.** 예약에 `connectors`를 지정해야 할 수 있다. 시험 실행으로 먼저 확인할 것.
  - 소재가 모자라면 건수를 억지로 채우지 말 것. 소재를 보도자료 밖으로 넓힐지는 사용자 결정.
- **법적 검수**: 편집국의 AI 검수는 `articles.legal_check`(jsonb)/`legal_checked_at`에 저장된다 (`lib/ai-legal.ts`, `lib/legal-types.ts`). 제가 쓴 기사에 제 점검 기록을 남길지는 사용자 답을 기다리는 중이다 ("AI 점검, 법률 자문 아님"으로 밝힐 것). 월드쉐어 기사는 일반인 실명이 나와 먼저 확인할 것.
- **편집장 이름 확인**: 치앙마이 타임즈를 포함해 편집장 계정이 없는 매체는 사용자에게 이름을 묻고 `supabase/fix-starter-byline.sql` 방식으로 고친다.
- **뉴스폭탄 홈 슬라이드가 6장 중 3장만 보임**: 원인 미확인. "공개 전" 배지·기사 발행 시각을 확인해 달라고 안내했다.
- **사용자가 확인한다고 한 것**: 보도자료함 매체별 추천, 모바일 홈 대형 슬라이드, 개통 현황 새 단계, 최신 기사 칸 위치, 영상 교체(이용안내의 "영상 올리기·바꾸기").
- **사용자가 실행하는 SQL**: `supabase/gdpa-members-2026-10-3.sql`(실행 여부 미확인). `reporter-stats.sql`, `outlet-site-self.sql`은 실행했다고 했다.
- **영상 업로드 한도**: 뉴스폭탄 대표가 224MB 영상을 올릴 때 "Maximum size exceeded"가 났다. Supabase 대시보드 Storage → Settings의 "Upload file size limit"을 1GB 이상으로 올려야 한다 (Free 요금제는 50MB가 상한). 사용자 조치 대기.
- 제안만 하고 요청받지 않은 것: 번역 기능, 말레이시아 타임즈를 GDPA 그룹으로 옮기기, 업로드 시 사진·영상 압축/R2, 다른 안내 영상 다시 만들기.
