# 다음(Daum) 검색등록 작업서 — 크롬 Claude 패널용

> **이 문서를 읽는 Claude에게**
> 너는 크롬 브라우저의 확장 패널에서 사용자를 돕는 Claude야. 사용자는 아래 매체를 **다음(Daum) 검색등록**에 등록하려고 해. 이 문서는 필요한 정보와 순서, 지켜야 할 규칙을 모두 담은 작업서야. 이 문서 밖의 값은 지어내지 말고, 모르면 사용자에게 물어봐.

## 0. 배경

- IM 뉴스룸으로 운영하는 인터넷 신문(매체)의 홈페이지를 검색엔진에 알리는 작업이야.
- 구글 서치콘솔과 네이버 서치어드바이저는 따로 신청해야 하고, **다음(카카오)은 `register.search.daum.net`의 "검색등록"으로 따로** 신청해야 해. 등록해도 노출이나 순위가 보장되는 건 아니야.
- 사이트 쪽 준비는 끝나 있어: 검색 허용(`robots` 메타·`robots.txt` 모두 허용), `/sitemap.xml`과 `/news-sitemap.xml`이 열림, 다음 크롤러로 접속해도 정상 응답(200). 너는 **다음 등록 화면에서 신청서를 채우는 일**만 하면 돼.
- 반영까지 자료마다 3~7일 또는 3~15일로 다르게 안내돼 있어. 심사 결과는 신청자 이메일로 와.

| 카테고리 | 뉴스/언론 계열 (없으면 농업·농림 계열). **보이는 선택지 이름을 사용자에게 먼저 보여 주고 고르게 해** |
| 사이트맵 | `https://chunghyup.com/sitemap.xml` |
| 신청자 이름 | **사용자에게 물어봐** (아직 모름) |
| 신청자 이메일 | **사용자에게 물어봐** (아직 모름, 심사 결과가 오는 주소) |

## 2. 진행 순서

1. `https://register.search.daum.net` 를 열어. 로그인이 필요하면 **사용자에게 알리고 사용자가 직접 로그인**하게 해 (비밀번호·인증번호는 네가 입력하지 마).
2. **이미 등록되어 있는지 먼저 확인해.** 같은 주소가 목록에 있으면 새로 신청하지 말고, 상태(승인/검토 중/반려)와 날짜만 사용자에게 알려 주고 멈춰.
3. "신규 등록하기" → 검색등록 선택에서 **"사이트 검색"** 을 고르고 URL 칸에 위 사이트 URL을 입력해.
4. 사이트 제목, 설명, 카테고리를 위 표대로 입력해. 카테고리는 선택지를 먼저 보여 주고 사용자가 고른 것으로 해.
5. 신청자 이름과 이메일은 **사용자가 알려 준 값만** 입력해.
6. **약관 동의와 마지막 "신청/등록" 버튼을 누르기 전에**, 입력한 내용을 한 줄씩 보여 주고 사용자의 확인("눌러")을 받아.
7. 신청 후 화면에 나온 접수 결과 문구를 **그대로** 알려 줘.
8. 웹마스터 도구에 같은 도메인을 등록하는 화면이 보이면 안내만 해 줘: 도메인 뒤 `/sitemap.xml`을 입력하는 방식으로 사이트맵을 등록할 수 있어. 실제 등록은 사용자가 확인한 뒤에 해.

## 3. 규칙 (꼭 지켜)

- **신청/등록 버튼과 약관 동의는 사용자가 "눌러"라고 할 때만** 눌러.
- 이 문서와 사용자가 알려 준 값 외의 정보(회사명, 연락처, 이메일, 대표자 등)는 **지어서 넣지 마.** 모르는 칸은 사용자에게 물어봐.
- 이미 등록된 사이트를 **삭제·수정·재신청하지 마.** 상태만 보고해.
- 비밀번호, 인증번호, 개인정보는 보고서에 적지 않아.
- 화면이 이 문서와 다르거나(메뉴 이름·순서·입력 칸), 오류가 나면 **멈추고 화면에 보이는 문구를 그대로** 사용자에게 알려 줘.
- 사이트 제목과 설명은 실제 매체 정보 그대로 써. 사실과 다르면 등록이 거절되거나 엉뚱한 카테고리에 들어갈 수 있어.

## 4. 끝나면 이 형식으로 보고

```
매체: ______   작업 시각: ______
기존 등록 여부: 없음 / 있음(상태: …, 날짜: …)
입력한 값: 제목 … / URL … / 설명 … / 카테고리 … (신청자 정보는 입력했다고만 적기)
신청 결과 화면 문구: (그대로)
사이트맵 등록: 함 / 안 함 / 화면 없음
다음에 할 일: (예: 결과 메일 확인, 3~15일 뒤 다음 검색에서 `site:주소` 로 확인)
확인 못 한 것: …
```

## 5. 신청 후 확인 (며칠 뒤, 별도 작업)

- 다음 검색창에서 `사이트 주소`와 `"매체 이름"`을 각각 검색해 나오는지 확인해.
- 결과 메일(승인/반려)을 사용자에게 확인해 달라고 하고, 반려면 이유 문구를 그대로 옮겨 적어.
- 이 작업서의 사이트 준비 상태(검색 허용, 사이트맵)가 바뀌었는지 의심되면 `https://주소/robots.txt` 와 `https://주소/sitemap.xml` 을 열어서 확인해 줘.
