## 연결하는 방법
1. 새 영상을 유튜브에 올린다 (기존 영상은 지우지 않고 그대로 둔다).
2. `lib/help-videos.ts` 의 `press` 항목 `youtube` 값을 새 영상 번호로 바꾼다. (또는 편집국 "영상 올리기"에 mp4 직접 올림)
3. 같은 파일 `press` 설명에 "여러 건을 한꺼번에 만드는 방법"을 한 줄 덧붙이면 좋다.

## 화면이 바뀌면 다시 찍어야 하는 곳
| 바뀌는 곳 | 영향 받는 구간 |
|---|---|
| 보도자료함 탭·검색·체크 목록 | 1단계~2단계, 7단계 (0:28~2:23, 6:12~) |
| 상세 화면 아래 세 버튼 | 3단계 (2:23~3:04) |
| 기사 수정 화면(메모 상자·섹션·사진 설명·저장·검수·승인신청 버튼) | 4~6단계 (3:04~6:12) |
| 여러 건 만들기(분량 버튼·진행 표시·결과) | 7단계 (6:12~8:04) |

## 화면과 다르게 말하지 않기 위한 메모
- 기사목록의 상태 글자는 "승인대기"가 아니라 **"승인신청"**이다 (여러 건 만들기 버튼 이름만 "…승인대기로"). 영상에서는 그대로 설명했다.
- 한 건씩 만들 때는 섹션이 비어 있어 직접 고르고, 여러 건을 만들면 에이아이가 섹션을 골라 넣는다 (맞는 섹션이 없으면 비움). 법적 검수는 여러 건 만들기에서는 하지 않는다.
- 승인신청하기를 누른 직후 편집 화면의 상태 글자는 새로고침 전까지 "작성중"으로 남을 수 있다 (영상에서는 기사목록으로 넘어가 보여 준다).
