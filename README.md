# IM CMS

언론사(뉴미디어타임즈 등 조건호님 인수 매체 포함)를 위한 자체 기사 관리 시스템.
엔디소프트/미디어온의 월 25만원 관리비용을 대체하는 것이 목표.

## 원칙
- **기능 우선, 디자인은 절제**: 상태(초안/검토중/발행됨)가 한눈에 보이는 것이 예쁜 것보다 중요
- 여러 매체(outlet)를 하나의 시스템에서 운영 (조건호님이 여러 언론사를 인수할 예정)

## 핵심 워크플로우
기자가 작성 → 편집장이 검토/승인 또는 반려 → 발행

## 역할(Role)
| 역할 | 권한 |
|---|---|
| reporter (기자) | 본인 글 작성/수정, 검토 요청 |
| editor (편집장) | 소속 매체 전체 글 검토/승인/반려/발행 |
| admin (관리자) | 매체·카테고리·회원 관리 포함 전체 권한 |

## MVP 우선순위 (1차 개발 범위)
1. 로그인 / 역할별 접근 제어 (Supabase Auth)
2. 기사 작성·수정 (에디터)
3. 기사 목록 + 상태 필터 (초안/검토중/발행됨/반려)
4. 편집장 승인/반려 플로우
5. 카테고리 관리
6. 이미지 업로드

## 이후 확장 (2차)
- 광고 관리
- SEO 메타태그
- 통계 대시보드
- 다매체(outlet) 전환 UI

## 기술 스택
- Next.js 14 (App Router) + TypeScript
- Tailwind CSS
- Supabase (Auth + Postgres + Storage + RLS)

## 시작하기
```bash
npm install
cp .env.example .env.local   # Supabase 프로젝트 키 입력
# supabase/schema.sql 을 Supabase SQL 에디터에서 실행
npm run dev
```
